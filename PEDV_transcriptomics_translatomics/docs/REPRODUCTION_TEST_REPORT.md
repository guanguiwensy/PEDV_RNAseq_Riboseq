# Reproduction test report

Scope: RNA-seq, Ribo-seq, comparative genomics (Fig 1-6, Sup 2-18). Tests were run **locally on Windows** with Python on copies of existing project data placed in a sandbox (`P`, `K`, `R` roots, outside this repository). Originals were not modified; no server was contacted; no sequencing data were re-analysed from FASTQ.

## Three levels (never merged)

* **L1 code provenance** – the script that made a figure/table is identified and archived.
* **L2 numeric check** – the script's regenerated data tables / printed values are compared with the stored ones (byte or value identity).
* **L3 figure reproduction** – the plotting script ran and produced a figure whose data and layout match the submitted one. Visual similarity alone is not claimed as reproduction; pixel comparison was **not** performed; Illustrator edits are not in code.

## Three reproduction classes (orthogonal to L1-L3; every test carries one)

* **A - replot from archived intermediate results**: the plotting script was run on stored source/plot-data tables; no statistic was recomputed.
* **B - recompute from analysis source tables**: the analysis script(s) were re-run on stored mid-level inputs (junction event tables, P-site count tables, HARTIS/PRICE start-level tables, ORF family tables). Stored inputs themselves come from server-side processing.
* **C - full reproduction from raw sequencing data (FASTQ -> trimming -> alignment -> counts)**: **NOT DONE for any figure.** Raw reads are not in this repository, the server was not used, and no BAM-level step was re-run. No result in this report may be read as class C.

Count by class: A = 11, B = 10, C = 0, not applicable = 1.
